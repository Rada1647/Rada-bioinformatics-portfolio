# Contributing and research integrity

This is an archived negative result with reusable reproduction code. Corrections
and independent reproductions are welcome. Include the exact command, environment,
input/source hashes, observed output, expected output, and whether a difference
changes a scientific conclusion. Do not upload source trajectories or coordinates.

Keep the original protocol, benchmark implementation and numerical outputs intact.
Put new hypotheses, alternative methods, expanded tuning grids and new datasets
in a separate protocol/version. Do not relabel post-outcome changes as prospective.

The project was developed with AI assistance. Five independent AI agents reviewed
mathematics, data provenance, statistics, citations, and numerical reproduction.
Those checks are documented, but are not human peer review, independent laboratory
validation, or a formal proof audit. A maintainer must assess corrections rather
than treating agent agreement as proof.

The name in CITATION.cff identifies the project maintainer's GitHub handle;
it does not assert academic affiliation or human peer-review status. Refer to
REFERENCES.txt for attribution to the mathematical and dataset authors.
